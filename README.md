# chiarorosa.github.io

Root of the `chiarorosa.github.io` GitHub Pages domain. Project sites are served by their own repositories under their own paths.

- `robots.txt` and `sitemap.xml`: crawlers only read these at the domain root, so they point to every project sitemap.
- `llms.txt`: summary for AI assistants.
- `index.html`: sends visitors to [CCT](https://chiarorosa.github.io/claude-codex-taskbar/), the main project ([source](https://github.com/chiarorosa/claude-codex-taskbar)).

When a new project gets a Pages site, add its sitemap to `robots.txt` and `sitemap.xml`.
